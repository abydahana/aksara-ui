# Transitions

Transition utilities provide common duration and easing presets.

::html
<div class="docs-preview">
  <button class="btn btn-primary transition duration-200 ease-in-out hover:bg-primary/80">
    Hover transition
  </button>
</div>
::end

```html
<button class="transition duration-200 ease-in-out hover:bg-primary/80">Hover</button>
```

Available:

- `transition`
- `transition-fast`
- `transition-slow`
- `duration-100`
- `duration-200`
- `duration-300`
- `duration-500`
- `duration-700`
- `duration-1000`
- `ease-linear`
- `ease-in`
- `ease-out`
- `ease-in-out`
