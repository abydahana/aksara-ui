# Ratio

Ratio helpers preserve a fixed aspect ratio for media.

::html
<div class="docs-preview">
  <div class="ratio ratio-16x9 bg-primary/10 rounded-12">
    <div class="flex items-center justify-center">16x9</div>
  </div>
  <div class="grid-3 gap-3">
    <div class="ratio ratio-1x1 bg-success/10 rounded-12"><div class="flex items-center justify-center">1x1</div></div>
    <div class="ratio ratio-4x3 bg-warning/10 rounded-12"><div class="flex items-center justify-center">4x3</div></div>
    <div class="ratio ratio-21x9 bg-info/10 rounded-12"><div class="flex items-center justify-center">21x9</div></div>
  </div>
</div>
::end
